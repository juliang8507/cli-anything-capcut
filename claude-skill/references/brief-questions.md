## Phase 1 — 기획 6개 (공통)

```markdown
영상 자동화 돌리기 전에 기획 6개만 확인할게요 (한 번에 답주시면 페이즈 2로 넘어갑니다):

1) **한 줄 요약**: 어떤 영상인가요? 용도+내용을 한 문장으로.
   예) "신규 출시한 제품을 소개하는 인스타 릴스 30초"

2) **시청자·목적**: 누가 보고, 보고 난 뒤 뭘 하길 원해요?
   예) "20~30대 여성, 예약 페이지 방문 유도"

3) **플랫폼·비율·길이**: 어디 올릴지 + 대략 길이
   (쇼츠=9:16/15~60s, 유튜브 본편=16:9, 릴스=9:16, 강의=16:9, 인스타 피드=1:1)

4) **소재 파일**: 가진 것들의 경로·종류·대략 개수
   예) "D:/촬영/room1.mp4, room2.mp4 + D:/bgm.mp3 + D:/logo.png"
   (없으면 "없음" — pexels-media 스킬로 전환 or 사용자 준비 대기)

5) **참고·레퍼런스**: 비슷한 영상 URL 1개 또는 무드 키워드 자유 서술
   예) "이 릴스처럼 https://... / '노을 감성'"

6) **전체 톤** (BOLD 3지선다 — 평균값 금지):
   A. **CINEMATIC** — film 필터, 어둡고 대비 강함, 느린 줌, subtitle-bottom 자막, BGM 잔잔
   B. **VIVID / SNS POP** — vivid 필터, 밝고 채도 높음, 빠른 컷, title-center 큰 글씨, BGM 신남
   C. **MINIMAL / CLEAN** — 필터 없음, 자연 색감, 차분한 페이드, 미니멀 자막, 전문적 나레이션
```

**Phase 1 체크포인트 포맷**:
```markdown
이렇게 이해했어요:
- 영상: [한 줄 요약]
- 시청자·목적: [...]
- 플랫폼·비율·길이: [9:16 포트레이트 30초]
- 소재: [...]
- 레퍼런스: [...]
- 톤: **[CINEMATIC / VIVID / MINIMAL]**

맞죠? 맞으면 Phase 2 넘어갑니다.
```

## Phase 2 — 타입별 6개

Phase 1의 1번·3번·5번 답에서 타입을 감지해 해당 세트를 한 메시지로 제시.

### Phase 2-A. 쇼츠·릴스 (9:16 짧은 영상)

```markdown
쇼츠·릴스 상세 6개:

7) **첫 3초 훅**: 시청자 멈추게 할 텍스트 또는 장면 한 개.
   예) "이거 모르면 가격 30% 더 낸다" / "남들 다 놓친 팁"

8) **스토리 흐름**: 3~5구간으로 나눠서 컷 순서·역할 알려주세요.
   예) "0-3s 훅 → 3-15s room1 소개 → 15-27s room2 뷰 강조 → 27-30s CTA"

9) **자막·강조 텍스트**: 제공하는 SRT 있음 / 장면별 강조 문구 몇 개 / 없음
   예) "장면마다 한 줄: 객실 종류, 뷰, 편의시설"

10) **BGM·오디오**: 분위기 + 볼륨 + 나레이션 유무
    예) "신나는 EDM, 볼륨 0.6, 나레이션 없음"

11) **컷 속도·트랜지션**: 빠른 컷(1~2s) / 중간(3~5s) / 느린(5s+), 전환 종류
    예) "빠른 컷 + flash 전환"

12) **CTA·엔딩**: 마지막 화면 문구 + 로고/워터마크 유무
    예) "'지금 예약' + 브랜드 로고 우하단"
```

### Phase 2-B. 이미지 슬라이드쇼

```markdown
슬라이드쇼 상세 6개:

7) **첫 장**: 타이틀 카드? 첫 사진? 훅 이미지?
   예) "'2024 여행' 타이틀 2초, 이후 사진들"

8) **장 순서**: 랜덤 / 파일명순 / 직접 순서 지정 / 스토리 순
   예) "파일명순 (날짜 찍혀있음)"

9) **자막·캡션**: 사진별 캡션 / 전체 타이틀만 / 없음
   예) "각 사진 하단에 날짜 + 장소 한 줄"

10) **BGM·오디오**: 분위기 + 길이 맞출지
    예) "잔잔한 피아노, 영상 길이에 맞춰 자동 조정"

11) **각 장 표시 시간·전환**: 1~5초, 트랜지션 종류
    예) "3초씩, dissolve 0.5s"

12) **엔딩**: 마지막 장 처리 + 페이드아웃
    예) "'Thanks' 타이틀 2s + fade_out 1s"
```

### Phase 2-C. 가사 영상

```markdown
가사 영상 상세 6개:

7) **오프닝**: 아티스트·곡명 카드? 바로 가사 시작?
   예) "아티스트 로고 2초 → 곡명 1초 → 가사 시작"

8) **가사 SRT**: 제공 파일 / whisper로 추출 / 직접 입력
   예) "D:/lyrics.srt (타이밍 수동 맞춤)"

9) **자막 스타일** (BOLD 3지선다):
   - **A. BIG BOLD**: 큰 폰트 center, 그림자 강함 (라이브 느낌)
   - **B. KARAOKE**: 노래방식 글자 색 바뀜 (내장 프리셋 `karaoke`)
   - **C. CINEMATIC SUB**: subtitle-bottom 작게, 흰색 (영화 자막 느낌)

10) **배경**: 단색 / 이미지 1장 / 짧은 영상 루프 / 아트워크
    예) "어두운 보라 단색 + 파티클 이펙트"

11) **비트 싱크**: 가사만 / 비트에 맞춰 이미지 플래시 / 구간별 전환
    예) "코러스에 flash 이펙트 넣기"

12) **아웃트로**: 곡 후반 처리 + 크레딧
    예) "마지막 5s fade_out + '© 아티스트' 크레딧"
```

### Phase 2-D. 강의·튜토리얼

```markdown
강의 상세 6개:

7) **인트로**: 강의 제목 카드? 바로 시작? 나레이터 소개?
   예) "제목 '엑셀 피벗 3분 마스터' 3초 → 본론"

8) **챕터 구조**: 몇 챕터, 챕터별 이름·시작 시각
   예) "1. 데이터 정리 (0s) / 2. 피벗 생성 (60s) / 3. 꾸미기 (120s)"

9) **자막·나레이션**: SRT 있음 / 자동 추출 / 나레이션 오디오 따로 / 없음
   예) "나레이션 narration.mp3 + 자동 SRT 추출"

10) **BGM·SFX**: 배경음 깔지? 클릭·강조 효과음?
    예) "배경음 볼륨 0.1 잔잔, SFX 없음"

11) **강조·시각화**: 화면 포인터 / 줌인 강조 / 밑줄 / 박스 강조
    예) "중요 부분 zoom_in 1.2배 + 노란 박스"

12) **엔딩**: 정리 슬라이드 / CTA(구독/다음 편) / 크레딧
    예) "핵심 요약 3줄 + '구독·좋아요' 3초"
```

### Phase 2-E. 제품 홍보

```markdown
제품 홍보 상세 6개:

7) **오프닝 훅**: 문제 제기 / 제품 노출 / 테스티모니얼
   예) "'이걸 몰라서 10만원 더 냈다' → 제품 노출"

8) **제품 노출 구조**: 어떤 순서로 USP 보여줄지
   예) "외관(3s) → 기능1 CLOSE-UP → 기능2 → 사용 장면 → 결과 before/after"

9) **메시지 텍스트**: 강조 카피 몇 개 + 숫자·배지
   예) "'업계 1위', '무료 체험', '30일 환불'"

10) **BGM·나레이션**: 분위기 + 볼륨. 나레이터 목소리·톤
    예) "드라마틱한 오케스트라 0.4, 남성 차분한 나레이션"

11) **브랜딩**: 로고 위치(인트로/아웃트로/워터마크) + 브랜드 컬러
    예) "인트로 3s 로고 + 우하단 워터마크, 메인 컬러 #FF6B00"

12) **CTA**: 마지막 액션 문구 + 링크·QR + 지속 시간
    예) "'지금 구매 yourbrand.com' 5초 + QR 코드"
```

### Phase 2-F. 브이로그·일상

```markdown
브이로그 상세 6개:

7) **오프닝**: 타이틀 카드 / 하이라이트 몽타주 / 바로 시작
   예) "'도쿄 3일차' 타이틀 2s + 도쿄타워 1컷 하이라이트"

8) **스토리 흐름**: 시간순 / 주제별 / 하이라이트 우선
   예) "아침 카페 → 점심 관광 → 저녁 야경 → 총평"

9) **자막·캡션**: 모든 대사 자막 / 핵심만 강조 / 없음
   예) "핵심 장면만 한 줄 코멘트"

10) **BGM·현장음**: BGM 분위기 + 현장음 유지 / 제거
    예) "Lo-fi BGM 0.3, 현장음 0.7 유지"

11) **컷 속도**: 빠른 편집(1-2s) / 중간(3-5s) / 느린 감성(5s+)
    예) "중간 속도, 감성 씬은 5~7s 길게"

12) **엔딩·다음 편 예고**: 결말 감상 + 다음 편 링크 / 구독 유도
    예) "'다음은 오사카' 3s + 구독 카드 2s"
```

### Phase 2-G. 인터뷰·토크

```markdown
인터뷰·토크 상세 6개:

7) **오프닝**: 인터뷰이 소개 카드 / 하이라이트 미리보기
   예) "이름·직함 카드 3s → 화자 0.5s 미리보기"

8) **스토리 흐름·편집 구조**: 질문별 구분 / 주제별 재편집 / 풀 타임라인
   예) "5개 질문, 질문별 장 구분"

9) **자막 (필수)**: 모든 대사 자막 / 핵심 발언만
   예) "전체 대사 SRT, 한국어, youtube-subtitle 스타일"

10) **로우어-서드 (이름·직함)**: 화자 바뀔 때 표시 / 한 번만 / 없음
    예) "질문당 1회 표시, 5s 노출"

11) **BGM·현장음**: BGM 사용 여부 (있으면 볼륨 낮게 0.1 권장)
    예) "BGM 0.1 잔잔, 목소리 선명"

12) **아웃트로**: 핵심 발언 재생 / 크레딧 / CTA
    예) "핵심 인용 1개 2s + 크레딧 3s"
```

## Phase 3 — 출력·디테일 4개 (공통)

```markdown
마지막 4개만 확인하면 렌더까지 자동으로 돌립니다. 세부 조정 없으면 "디폴트"라고만 답주세요:

13) **필터·색보정 강도**: 자동(톤에 맞춤) / 사용자 지정 수치
    디폴트 — CINEMATIC: `cinematic` 0.4 + brightness -0.05 + contrast 0.15
            VIVID:     `vivid` 0.5 + saturation 0.15
            MINIMAL:   필터 없음 + 기본 색감

14) **인트로·아웃트로 애니메이션 강도**
    디폴트 — 쇼츠/릴스: intro `zoom_in` + outro `fade_out`
            강의:    없음
            홍보:    intro `fade_in` + outro `fade_out` + CTA `bounce_in`

15) **렌더 방식**:
    A. `render` (CapCut GUI 경유) — 정확함, 모든 필터 반영, 느림, GUI 필요
    B. `render-headless` (ffmpeg 직접) — 빠름, 일부 필터/효과 미지원, 무인 서버 OK
    디폴트 — 프로덕션/최종: A / 프리뷰·반복 테스트: B

16) **출력**: 해상도(720P/1080P/2K/4K) + 저장 경로·파일명
    디폴트 — 1080P, 프로젝트 폴더에 `<name>_<timestamp>.mp4`
```

<a id="defaults"></a>
## 디폴트 정책

사용자가 특정 항목에 "아무거나" / "몰라요" / "디폴트"라고 답하면 아래를 적용하고 **명시**:

| 항목 | 디폴트 |
|------|-------|
| BGM 분위기 | 쇼츠=신남, 릴스=트렌디, 강의=잔잔, 홍보=드라마틱, 브이로그=Lo-fi, 가사=곡 무드 따름 |
| BGM 볼륨 | 일반 0.3 / 나레이션 있으면 0.15 / SFX 1.0 |
| 자막 스타일 | `youtube-subtitle` (내장) |
| 자막 위치 | `subtitle-bottom` |
| 이미지 duration | 3초 |
| 트랜지션 duration | 500ms |
| 인트로 애니메이션 | 쇼츠/릴스=zoom_in, 강의=없음, 홍보=fade_in, 브이로그=fade_in |
| 아웃트로 애니메이션 | fade_out 0.5~1s |
| 컷 속도 | 쇼츠=1~3s, 강의=5~10s, 브이로그=3~5s, 홍보=2~4s |
| 필터 | CINEMATIC=cinematic 0.4, VIVID=vivid 0.5, MINIMAL=없음 |
| 색보정 | CINEMATIC: brightness -0.05 + contrast 0.15 / VIVID: saturation 0.15 / MINIMAL: 기본 |
| 렌더 방식 | 최종=render (GUI) / 반복 테스트=render-headless |
