# 콘텐츠 공식·수치 — 훅·템포·BGM

> **이 파일의 역할**: 에이전트가 Phase 2(구조·상세)에서 훅 문구·컷 길이·BGM을 결정할 때 정량 수치 근거.
> **언제 읽나**: Brief Phase 2 질문·답변 처리 시. 특히 쇼츠·릴스(시간 예산 빡빡) 작업에서.

## 1. 훅 라이브러리 — 첫 3초 공식

### 1.1 알고리즘 데이터 (2026)

| 지표 | 값 |
|------|-----|
| 바이럴 진입 완주율 | **70%+** |
| 첫 3초 이탈 허용치 | 30% 미만 |
| 음소거 시청 비율 | **60%+** (텍스트 훅 필수) |
| 미스리딩 훅 페널티 | 도달 **-60~80%** |
| 훅 길이 권장 | **2~2.5초** 내 완결 |
| 텍스트 오버레이 | 2초 이상 노출, 5~8 단어, 고대비 |

**3겹 레이어 골든 공식**: 텍스트 + 비주얼 + SFX 동시 → 3-second hold **3배**.

### 1.2 훅 10 카테고리 (실전 예시)

#### 1) 호기심 갭 (Curiosity Gap)
공식: 정보 일부만 노출 → 뇌가 빈칸 채우려 함

한국어: "이거 끝까지 봐야 진짜가 나옵니다" / "아무도 안 알려주는 ○○의 진짜 이유" / "20년 업계 베테랑이 절대 안 하는 행동 1가지"
영어: "I probably shouldn't share this, but…" / "No one talks about this in [industry]…"
연출: 첫 프레임 모자이크 + 0.4초 zoom-in + woosh SFX

#### 2) 숫자/리스트
공식: 구체 숫자 + 약속 + 차별점

한국어: "업계 종사자만 아는 꿀팁 3가지" / "80% 사람들이 모르는 방법 7가지" / "매출 2배 만든 단 1가지 행동"
영어: "The 3 mistakes everyone makes" / "5 things I do before every flight"
연출: 카운트다운 5..4..3.. + 매 항목 0.3초 flash

#### 3) 반전/패턴 인터럽트
공식: 예상 흐름 의도적 파괴 → retention 평균 **+23%**

한국어: "다들 ○○하지 마세요. 진짜로요" / "근데 이거 알면 충격받습니다" / "잠깐, 이거 보고 가세요"
영어: "Wait, this changes everything" / "Stop scrolling if you're a [target]"
연출: 0~0.3초 freeze frame + 색반전 + shake + record scratch

#### 4) 약속/혜택
공식: 시간 단위 + 측정 가능한 결과

한국어: "이 영상 30초만 보면 ○○ 해결됩니다" / "오늘부터 30% 아끼는 법"
영어: "Master the J-cut in 30 seconds" / "This 5-second edit doubled my watch time"
연출: Before/After 분할 화면 + 결과 2초 teaser

#### 5) 논란/반대 의견 (⭐ 230만뷰 검증)
공식: 통념 + "사실은 반대다" + 근거 약속

한국어: **"대기업은 너가 일을 잘해서 돈을 많이 주는 게 아니야. 규칙을 잘 지키는 값으로 돈을 주는 거야"** (신윤주, 230만 뷰)
한국어: "유명 앱이 더 싸다고요? 거짓말입니다" / "비싼 게 좋다는 건 마케팅 사기예요"
영어: "Everyone's doing [common practice] wrong"
연출: "X" 빨간 오버레이 + 진지한 클로즈업 + 단호한 톤

#### 6) 공포/손실 회피
공식: 손실 회피는 보상 추구보다 **2배 강한 동기** (Kahneman)

한국어: "이거 모르고 예약하면 호구됩니다" / "이 실수 한번에 230만원 날렸습니다"
영어: "This one mistake cost me $2,300"
연출: 어두운 톤 + 빨간 경고 + 사이렌 SFX 절제 + 진지한 표정
⚠️ **실제 가치 없으면 misleading 판정 → 60~80% 페널티**

#### 7) 질문
공식: 직접 질문 → 시청자 자기 답 떠올림

한국어: "왜 우리 매장만 평점이 낮을까요?" / "이 둘 중에 뭐가 진짜 같으세요?"
영어: "Did you know that honey never expires?"
연출: 화면 가운데 큰 텍스트 질문 + 2개 선택지 분할

#### 8) 권위/신뢰
공식: 전문성·경력·숫자로 신뢰 확보

한국어: "20년 업계 베테랑이 알려드립니다" / "데이터 200만 건 분석해보니까"
영어: "After interviewing 50 [experts], here's what they all do"
연출: 자격증/명함 첫 프레임 0.5초 → 본론

#### 9) POV / 공감 시뮬레이션 (⭐ 178만뷰 검증)
공식: 시청자 처한 상황 묘사 → "이거 내 얘기"

한국어: **"여기 꼬집을 수 있으면 동안상 50%"** (지혜, 178만 뷰) / "POV: 매장 줄 30분 기다린 당신"
영어: "POV: You're [relatable situation]" / "Tell me you're a [type] without telling me"
연출: 1인칭 손/발 화면 + 일상 디테일 클로즈업 + 자연광

#### 10) 충격적 사실
공식: 통념 부수는 데이터 + "오늘 처음 알았어요"

한국어: "사실 ○○는 ○○가 아닙니다" / "한국인 90%가 잘못 알고 있는 ○○"
영어: "I was today years old when I found out…"
연출: 통계 카운트업 애니메이션 + 출처 자막(작게) + zoom-in

#### `preset hook --category` 매핑 (v0.4.1~)

CLI로 위 10개 카테고리를 한 줄로 자동 생성. shake intensity, flash duration, text animation이 카테고리별로 튜닝됨.

| 카테고리 번호 | `--category` 값 | 한 줄 예시 |
|-------------|----------------|-----------|
| 1) 호기심 갭 | `curiosity` | `preset hook -p p -t "이거 끝까지 봐야 진짜가 나옵니다" --category curiosity` |
| 2) 숫자/리스트 | `number` | `preset hook -p p -t "업계 종사자만 아는 꿀팁 3가지" --category number` |
| 3) 반전/패턴 인터럽트 | `pattern-interrupt` | `preset hook -p p -t "다들 ○○하지 마세요" --category pattern-interrupt` |
| 4) 약속/혜택 | `promise` | `preset hook -p p -t "30초만 보면 해결됩니다" --category promise` |
| 5) 논란/반대 | `contrarian` | `preset hook -p p -t "유명 앱이 더 싸다고요? 거짓말입니다" --category contrarian` |
| 6) 공포/손실 회피 | `fear` | `preset hook -p p -t "이거 모르면 호구됩니다" --category fear` |
| 7) 질문 | `question` | `preset hook -p p -t "왜 우리 매장만 평점이 낮을까요?" --category question` |
| 8) 권위/신뢰 | `authority` | `preset hook -p p -t "20년 업계 베테랑이 알려드립니다" --category authority` |
| 9) POV / 공감 | `pov` | `preset hook -p p -t "POV: 매장 줄 30분 기다린 당신" --category pov` |
| 10) 충격적 사실 | `shock` | `preset hook -p p -t "한국인 90%가 잘못 알고 있는 ○○" --category shock` |

### 1.3 시각 훅 기법 매트릭스

| 기법 | CapCut 구현 | 사용 타이밍 |
|------|-------------|-------------|
| Smooth Zoom-In | 키프레임 2개 + Cubic Out | 토킹헤드 첫 프레임 |
| Zoom + Shake | Zoom + Shake + Flash | 비트 드롭, 충격 사실 |
| Freeze Frame | 클립 분할 → 첫 프레임 0.5~1초 정지 | 호기심 갭, "잠깐" 패턴 |
| Color Invert Flash | Filter → Invert + 키프레임 | 패턴 인터럽트 |
| Velocity Ramp | Curve Speed → Custom | 결과 reveal 직전 |
| **3-Layer Stack** | 5~8단어 bold text + zoom + woosh ( → `preset hook` 이 자동 생성) | **모든 훅의 기본** |

### 1.4 한국 분야별 검증 공식 (HighOutputClub)

| 분야 | 공식 | 조회수 |
|------|------|--------|
| 논쟁/시사 | 보편 관심사 + 반직관 주장 | **230만** (신윤주) |
| 정보/리뷰 | 부정형 명령 + 공신력 ("사지 마세요 + 최하위 등급") | 9.5만 |
| 뷰티 | 직접 참여 + 오감 자극 | **178만** (지혜) |
| 타겟 호명 | 특정 인물 호명 + 고민 공감 | 15만 |
| 여행/큐레이션 | 차별화 선언 + 체험 정보 | 2.7만 |
| 자기계발/서사 | 권위 → 권위 파괴 → 고백 | 3.2만 |
| 음식/추천 | 극단 표현 + 이중 반전 | 11만 |

**한국 시장 3원칙**:
1. 첫 3초는 **감정** (놀람/공감/분노 중 1개 필수)
2. **열린 결론** — 정답 단정 금지 → 댓글 증가
3. **내 이야기 포함** — 정보형이라도 개인 경험 1줄

### 1.5 훅 안티패턴 (즉시 스와이프 유발)

❌ "안녕하세요 여러분~" / "오늘은 ○○에 대해 알려드릴게요" / "구독 좋아요 부탁드립니다" / "○○ 채널의 ○○입니다"
❌ AI 음성 클리셰: "저 됐어요!", "큰일났어요 여러분" (알고리즘 AI slop 다운랭킹)
❌ 과도한 모자이크 미끼 (끝까지 가리기 → TikTok 2026 misleading 페널티)
❌ 재활용 워터마크 (다른 플랫폼 로고 → 도달 -60%)
❌ clickbait 미스매치 (훅 약속이 본문에 없음 → -60~80%)

## 2. 컷 템포 공식

### 2.1 장르별 평균 컷 길이 (ASL)

| 플랫폼·장르 | 평균 컷 | 시청자 결정 시간 |
|-------------|---------|-----------------|
| TikTok · Shorts · Reels | **1.5~2.5초** | 1.7초 내 스크롤 결정 |
| 광고 (30초) | **1~1.2초** | 25~30컷 압축 |
| VLOG | 3~5초 | - |
| 유튜브 본편 (리뷰·엔터) | 3~8초 | - |
| 튜토리얼·강의 | 5~10초 | 정보 손실 방지 |
| 다큐멘터리 | 8~15초 | - |
| 영화 (2020년대) | 2.5초 ASL | (1930년은 12초) |
| Bourne (2007) | **2.0초** | 액션 기준 재정립 |
| 뮤직비디오 | 1.5~3초 | 비트 싱크 |
| 한국 예능 (워크맨) | 0.5~2초 | 자막 주도 |
| 한국 강의 (슈카) | 6~12초 | 정보 중심 |

### 2.2 템포 변화 곡선 (Freytag 영상판)

5분 영상 예시:
- **Hook (0~3s)**: 1.5초 ASL, 2~3컷 밀집
- **Body (3s~2m30s)**: 5~6초 ASL, 40~50컷
- **Climax (2m30s~3m)**: 3초 ASL, 10~12컷 가속
- **Outro (3m~5m)**: 7초 ASL, 15~20컷 감속

**합계**: 약 68~70컷

⚠️ 유튜브 리텐션 곡선상 **첫 30초 35%+ 이탈**하면 후크 실패 판정.

### 2.3 비트 싱크 (음악 영상·쇼츠)

공식: **60 / BPM = 비트당 초**
- 120 BPM → 0.5초마다 비트 → 2~4컷마다 컷 체인지
- 90 BPM → 0.67초마다 비트 → 감성 영상
- 140 BPM → 0.43초마다 비트 → EDM·바이럴

**효과**: 강한 오디오-비주얼 동기화 시 **완료율 +40%** (Facebook 연구)

### 2.4 편집 기법 사용 타이밍

| 기법 | 정의 | 언제 |
|------|------|------|
| **L-cut** | 오디오가 앞 컷에서 이어짐 | 대화 자연스럽게 |
| **J-cut** | 오디오가 다음 컷보다 먼저 시작 | 긴장감, 리드인 |
| **Match cut** | 형태·움직임 유사한 두 컷 연결 | 시네마틱 전환 |
| **Jump cut** | 같은 앵글 컷 연속 (3~5초 간격 Reels → +32% 인게이지) | 토킹헤드, 빠른 편집 |
| **Cut on action** | 동작 중간 컷 전환 | 연속성 보존 |

⚠️ Jump cut 5회 이상 연속 → 비전문 인상

### 2.5 안티패턴

❌ 모든 컷을 같은 길이로 (AI 자동편집 1순위 지문 — Pictory "every scene roughly the same screen time")
❌ 모든 컷 사이 dissolve 트랜지션 (전체의 5% 이하만 사용, 시간·장소 전환에만)
❌ 비트 무관 컷 (BGM 있는데 컷이 엉뚱한 타이밍)
❌ 쇼츠에 10초 컷 (이탈)
❌ 강의에 1초 컷 (정보 손실, 멀미)

### 2.6 라이프스타일·럭셔리 콘텐츠 권장

| 용도 | ASL | 구조 |
|------|-----|------|
| 라이프스타일 릴스 (30s) | 1.5~2.5초 | 훅 3초 + 외관→공간→제품 1초씩 + CTA |
| 라이프스타일 피드 영상 (60s) | 3~5초 | 제품 정적 5~8초 + 디테일 1~2초 강약 |
| 브랜드 시설 롱폼 (3min) | 5~8초 | A(외관)→B(시설)→C(제품) 3블록 |
| 직원 교육 영상 | 6~10초 | 정보 명료성 우선, 워크맨 스타일 금지 |

## 3. BGM 매칭

### 3.1 볼륨 황금률

**VO 대비 -18~-20 dB** (15 미만 = 마스킹, 25 초과 = 안 들림)

플랫폼별 LUFS:
- YouTube: **-14 LUFS**
- TikTok: -10~-12 LUFS
- Reels: -10~-14 LUFS

### 3.2 장르별 BGM 매트릭스

| 영상 타입 | 추천 장르 | BPM | 볼륨 | 페이드 in/out | 비고 |
|-----------|----------|-----|------|--------------|------|
| **쇼츠·릴스·틱톡** | 트렌드 EDM·팝 | 120~140 | 0.5~0.7 | 0.2s / 0.3s | 짧고 강한 훅 |
| **브이로그** | Lo-fi·chillhop | 70~90 | 0.3~0.4 | 1s / 2s | 현장음 0.7 유지 |
| **여행** | indie folk·cinematic post-rock | 80~110 | 0.35 | 1.5s / 2.5s | - |
| **제품 광고** | 드라마틱 오케스트라·모던 일렉트로 | 100~130 | 0.4 | 0.5s / 1s | - |
| **강의·튜토리얼** | 잔잔 앰비언트·피아노 | 60~80 | **0.1~0.15** | 1s / 2s | 나레이션 우선 |
| **💎 럭셔리·라이프스타일** | 시네마틱 오케스트라·스무스 재즈 | **70~90** | 0.3 | 0.3s / 0.5s | 라이프스타일 쇼츠=Smooth jazz 75~85 |
| **뷰티·패션** | 업비트 팝·일렉트로 | 110~130 | 0.5 | 0.3s / 0.5s | - |
| **요리·푸드** | bossa nova·swing·밝은 Lo-fi | 100~120 | 0.4 | 0.5s / 1s | - |
| **뮤직비디오** | 곡 본체 | - | 1.0 | 0s / 2s | BGM 별도 없음 |
| **인터뷰·토크** | 잔잔 BGM | 60~80 | **0.1** | 1s / 2s | 목소리 선명 우선 |

❌ SFX 전혀 없음 또는 지나침 (whoosh·tick 남발)
❌ 나레이션 TTS 티 나는 목소리 (후처리 없이)
❌ 모든 영상에 같은 BGM 반복
❌ 페이드 없이 뚝 끊김
❌ 비트 강한 BGM + 비트 무관 컷
❌ 감성 영상에 일렉트로, 에너제틱 영상에 앰비언트

## 4. 에이전트 적용 워크플로우

### 훅 결정 (Phase 2-7)
1. 사용자 영상 주제·타겟 확인
2. 이 파일 1.2~1.4 섹션 참조 → **카테고리 2~3 추천**
3. 한국 분야별 검증 공식(1.4)에서 가장 가까운 것 선택
4. 한국어 예시 1~2개 변형해 제시
5. 안티패턴(1.5) 체크리스트 통과

### 컷 템포 결정 (Phase 2-11)
1. 타입·플랫폼 확인 → 2.1 표에서 ASL 수치 추출
2. 영상 길이 × ASL 계산 → 컷 개수 추정
3. 템포 곡선(2.2) 적용 — 훅 밀집 / Body 안정 / Climax 가속 / Outro 감속
4. 비트 싱크 필요하면 2.3 공식 (60/BPM)
5. 안티패턴(2.5) 체크

### BGM 결정 (Phase 2-10)
1. 영상 타입·분위기 → 3.2 매트릭스에서 장르·BPM·볼륨·페이드 수치 추출
2. 나레이션 유무 확인 → 볼륨 조정 (있으면 -22 dB)
3. 3.3 무료 소스에서 사용자에게 추천 (예산 확인 후 Epidemic)
4. 안티패턴(3.4) 체크
